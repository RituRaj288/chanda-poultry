## Deploying to Vercel (Zero-404 Embedded Logos & Images)

This project includes a `vercel.json` configuration and **Embedded Base64 Brand Assets** inside `js/site-config.js` and `js/main.js`.
- Even if a nested `assets/images/` folder is omitted during a manual GitHub upload or accessed via clean URLs (`/about`, `/services`), all official logos and product showcase images automatically render from the embedded Data URI store (`window.EMBEDDED_BRAND_IMAGES`).
- To update your live Vercel deployment, make sure to upload/commit the updated `js/site-config.js`, `js/main.js`, `vercel.json`, and HTML files.
